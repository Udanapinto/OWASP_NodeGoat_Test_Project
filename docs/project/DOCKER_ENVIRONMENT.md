# Docker Development Environment

## Purpose

Docker Engine and Docker Compose are used to provide the local,
controlled and reproducible runtime environment for the IE3142
NodeGoat DevSecOps project.

## Installation Method

Docker Engine installed using Docker's official Ubuntu APT repository.

Installed components:

- Docker Engine
- Docker CLI
- containerd
- Docker Buildx
- Docker Compose Plugin

## Standard Commands

Check Docker:

```bash
docker --version
docker info
