# Ethical and Security Testing Boundaries

## Allowed

Testing may be performed only against:

- Our authorised local OWASP NodeGoat copy
- Docker containers created specifically for this university project
- Test data created by our group
- Localhost services used by this project

## Prohibited

The group will not:

- Attack public websites
- Attack external NodeGoat instances
- Scan third-party servers
- Scan third-party APIs
- Use real user credentials
- Access real personal data
- Attempt unauthorised access
- Perform attacks outside the IE3142 project environment

## Vulnerability Demonstrations

All exploitation will be:

- Controlled
- Local
- Educational
- Reproducible
- Documented
- Limited to the assignment scope

## Data

Only synthetic/test data will be used.

Real confidential, personal, financial or authentication data
must not be introduced into the laboratory environment.

## Security Tools

The following security tools may be used against the local project:

- Burp Suite
- Semgrep
- npm audit
- Gitleaks
- Trivy
- OWASP ZAP

## Important Rule

No vulnerability testing will begin until the group's Ethical
Clearance Form has been completed according to the module
requirements.
